# ورقك

مرجعية لكل خطوة في حياة الشركة: التأسيس، والتشغيل، والنمو، والتخارج أو التصفية.

## التشغيل

تطبيق مبني على:

```
Next.js
```

وقاعدة البيانات والدخول على:

```
Supabase
```

للتشغيل على جهازك:

```
npm install
npm run dev
```

| المسار | الوظيفة |
|---|---|
| `app/` | صفحات المنصة، صفحة لكل مسار |
| `components/` | شاشات كل دور، والدخول، والهيكل المشترك |
| `lib/` | الاتصال بقاعدة البيانات، والتنسيق، وقواعد المستندات والطلبات |
| `supabase/migrations/` | جداول قاعدة البيانات والصلاحيات، بنفس ترتيب تطبيقها |

## الأدوار

| الدور | بيعمل إيه |
|---|---|
| `owner` | صاحب العمل |
| `office` | المكتب المنفذ |
| `admin` | مدير المنصة |

الدخول بالدعوة بس في النسخة التجريبية. المدير يضيف الدعوة، والشخص يدخل ببريده وياخد دوره تلقائياً.
